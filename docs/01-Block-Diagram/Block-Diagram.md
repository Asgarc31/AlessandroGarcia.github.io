## Overview
This diagram shows the circuit that involves a force sensor, voltage regulator, op-amp, speaker, LED, and a PIC nano provided by the class. These parts have been selected because they have already been tested in class, meaning I have some prior experience with them. As for the type of sensor, I decided on an IR sensor because it is useful when measuring shorter distances. The circuit will be supplied with a 5V power supply and will also be connected both the circuit with the force sensor as they will need to work in conjunction to meet our standards for the trash can's alert system. Once the value for the IR sensor has reached a certain threshold, the PIC will send a signal for the speaker to alert the user that the trash is at capacity and needs to be thrown out.
