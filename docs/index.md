## Introduction

This datasheet has been created to document my contributions to the Trash Canner project. In this datasheet I will show my block diagram, component selection, bill of materials, schematic design, and power budget.

### Project Summary

 The Trash Canner project is showcase our team's process on designing an automatic trashcan that uses a force and distance sensor. The force sensor will read the total weight of the trash in the can and use a LED scale to show how close the contents of the can are to the recommended weight capacity to prevent the bag from ripping. The distance sensor will detect the can's rough fullness and alert the user to take out the trash via sound cue when it reaches the suggested maximum capacity. A link to the team report can be found [here.](https://asu-egr304-2025-f-207.github.io/)


### My Contribution

My contribution to this project is the distance sensor subsystem. The distance sensor will activate once the lid of the trashcan is closed. Once activated, the sensor will start reading values based on how close the trash is to the lid. After the trash gets too close to the sensor, the sensor will send a signal to cue a sound to play that alerts the user to change trashbag because it is at maximum capacity.
